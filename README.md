A responsive front-end web application and student information portal designed for **Noida International University (NIU)**. This project showcases a modern, accessible UI/UX concept featuring academic program directories, admission workflows, and interactive campus resources.

## ✨ Key Features

* **Responsive Layout:** Fully adaptive design optimized for desktop, tablet, and mobile viewports using CSS Flexbox and Grid.
* **Academic Schools & Programs Directory:** Structured navigation covering engineering, biotechnology, sciences, and management departments.
* **Admissions & Inquiry Section:** Interactive forms with client-side validation for prospective student applications and brochure downloads.
* **Campus Highlights & Notice Board:** Dynamic announcements, upcoming university events, and virtual campus tour sections.
* **Clean, Semantic Markup:** Built with SEO-friendly HTML5 tags and modular CSS styling for fast load times and easy maintainability.

---

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic elements, accessible forms)
* **Styling:** CSS3 (Custom variables, Flexbox, CSS Grid, media queries, animations)
* **Scripting:** Vanilla JavaScript (DOM manipulation, navigation toggles, form validation)
* **Icons & Fonts:** Font Awesome / Google Fonts
* **Version Control:** Git & GitHub

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites

Any modern web browser (Chrome, Edge, Firefox) and a code editor like **VS Code** (with the *Live Server* extension recommended).

### Installation

1. **Clone the repository:**
```bash
git clone [https://github.com/your-username/niu-web-portal.git](https://github.com/your-username/niu-web-portal.git)

```


2. **Navigate to the project directory:**
```bash
cd niu-web-portal

```


3. **Launch the project:**
* Open `index.html` directly in your browser, **or**
* Right-click `index.html` in VS Code and select **Open with Live Server**.
